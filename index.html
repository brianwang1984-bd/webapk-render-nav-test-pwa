How to tell what happened

If the WebAPK launched, the next screen is standalone (no Chrome address bar) and says standalone (installed WebAPK / PWA). If the bug reproduced, the next screen is still a Chrome tab.

Setup

  1. On Android S+, open the PWA in Chrome and install it as a WebAPK from the Chrome menu (Install / Add to Home screen).
  2. After the WebAPK is installed, sometimes the domain verification status becomes non-verified.
  3. Come back to this out-of-scope test start page in a Chrome tab (not the installed app) and tap the button.
